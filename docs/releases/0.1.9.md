# BiliSkip 0.1.9

日期：2026-10-02。扩展0.1.9，油猴0.1.9.0。本地安装包交付，公开商店版本按各自审核流程更新。

## 更新

- 接入经过1000条社区对照实测的仅广告JSON v2提示词。输入为标题和编号字幕，输出主题与独立广告分段，保留广告之间穿插的正文。
- DeepSeek非思考模式，JSON输出上限8192 tokens。新缓存身份`ad-cues-v6-json`与v1–v5分别积累；原Key、设置、旧标记保持。
- 扩展设置页缓存列表增加10／20／50条前端分页，加载全部记录，导出包含全部记录。
- 本地语音转写区块增加独立的「上传转写字幕用于准确度评估」开关，默认开启，可关闭。新转写结果上传视频信息、完整文本、时间戳、字幕指纹与ASR／客户端版本；音频留在本机。
- 后端`POST /v1/transcripts`已先上线：512KiB上限、指纹校验、去重回执、独立待核验数据表，与广告提交共用每IP每1000ms一次的限流。
- 保留空Key共享缓存模式、ASR与模型资源锁拆分。上传失败保留本地字幕与广告分析结果。
- 共享提交从上次响应后间隔至少1000ms，适配连续的字幕和广告结果上传。
- 更新Edge免凭据认证说明，提供已在线缓存的公开MC演示。
