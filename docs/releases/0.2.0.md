# BiliSkip 0.2.0

准备日期：2026-10-08。扩展 `0.2.0`，油猴 `0.2.0.1`。

## 更新内容

- 整合蓝色电视／金币图标、播放器入口、右侧面板、分区导航与自动保存设置。
- 新增共用「宠物」分区：显示开关、镜像贴边、图片上传裁剪和本机音频上传。
  默认使用已选定的角色与小黄鸭音效，点击音量为10%；正式构建可在设置中开启宠物。
- 气泡采用单标题、蓝色细边框和逐泡入场动画，默认向右展开，空间不足时向左展开。
  关闭按钮跟随镜像，左右布局均支持贴底，右侧拖动为滚动条预留安全距离。
- 默认台词归并为7组，迁移旧标题／说明和占位符；缓存命中保持静默，点击显示待机台词。
  异常统一提示「搞不定啦！打开面板自己看一下~」。
- 按收到用量时的北京时间价档固定一个本次参考费用，历史记录沿用已保存金额。
- 首次显示等待设置加载完成，直接应用镜像、图片及位置；面板入口使用居中对齐的插件Logo。

## 升级与验证

提示词继续使用 `ad-cues-v6-json`，模型、广告缓存身份与ASR字幕协议保持原值。
宠物台词采用版本4迁移；已保存的图片、音量、音频及其他设置继续保留。
正式油猴沿用原名称与命名空间，扩展与油猴分别使用各自的本地存储。

固定回归、模拟浏览器及真实试用范围见[宠物验收](../testing/pet-preview-2026-10-08.md)，
本轮正式包核对见[打包验收](../testing/release-0.2.0-2026-10-08.md)。
