# 宠物本地预览

这版用于确认角色大小、点击摸头、拖动、识别费用气泡及宠物自定义设置。
扩展与油猴共用 `pet.js` / `pet-state.js` 和 `lib/pet-settings-view.js`。
保持当前应用版本和分析协议；发布预设保留关闭状态，本地预览构建单独启用。

## 预览方式

- 独立页面：打开 `dist/biliskip-pet-preview/index.html`，按钮触发明确标注的模拟状态，模型调用为零。
- Chrome：停用其他 BiliSkip 实例，加载 `dist/biliskip-pet-preview/extension/`，刷新 B站视频页面。
- 页面启动及恢复时，宠物等待已保存设置加载完成，应用图片、镜像和位置后首次显示。
- 油猴：安装 `dist/biliskip-pet-preview/biliskip-pet-preview.user.js`，同一页面启用一份 BiliSkip。
- 完成单击后触发压扁回弹、点击音效并显示当前配置的待机台词，6 秒后收起；拖动超过 6px 后进入移动模式。
  点击展示与自动事件提示分别管理，后续自动跳过、识别完成或异常仍按新事件提示。
- 气泡 6 秒后收起，识别中持续显示；全屏自动收起；× 在本页隐藏，刷新恢复。
- 拖动期间气泡保持显示，松手后重新计时 6 秒；拖动中完成识别也沿用这一规则。
- 自动跳过时显示「跳过 N 秒恰饭片段~ 吃点白饭不过分吧！」，按本次跨过的广告时长提示。
  每次跳过显示 6 秒；撤销、刷新、切换视频后恢复对应状态，重复跳入广告会产生新提示。
- 气泡使用白色填充、2px 蓝色细边框、柔和阴影和两颗思考小泡泡。两个角色朝向都优先向右展开，右侧空间不足时转向左边，
  两侧都受限时将气泡保持在视口内。气泡方向独立于角色镜像。
- 小泡泡、大泡泡、主气泡和文字按 0 / 130 / 260 / 360ms 依次出现；重新打开时重播，
  同一状态轮询与拖动保持动画进度。系统选择减少动态效果时直接显示。
- 「打开视频面板」进入既有面板。交互组件只订阅现有任务状态。

费用沿用本项目 token × 单价的估算，收到用量时选择一个时段并固定金额；本地及共享缓存命中时，宠物保持静默。
只有在当前页面观察到新任务开始后，才展示该任务的完成费用；历史缓存中的 usage 保持历史含义。
本版关注单次任务提示，累计账本留作后续功能。

## 宠物设置

Chrome 设置页的「宠物」分区、油猴设置面板的「宠物」分区提供相同配置：

- 显示开关、左右镜像并默认置于左下角、点击音效开关与 0–100% 音量，默认音量 10%。
  现有自行保存的音量继续保留。
- 「上传点击音频」接受 MP3、WAV、OGG、M4A，文件最大 1 MiB、时长最多 10 秒。
  上传后作为单段点击音效播放，沿用音量与音效开关；「恢复默认音效」恢复小黄鸭两段音效。
  音频在本机检查格式和时长，保存在扩展本机存储或 GM 存储，界面关闭时清理临时资源。
- 镜像时关闭按钮同步移到左上角，角色默认贴齐左边与底部。各任务状态及按压 / 识别动画保持底部对齐；
  拖动可以贴齐视口边缘，停靠底部后随窗口大小变化保持贴底。
- 右侧拖动使用扣除滚动条后的可用宽度，并保留按压动画安全区；浮动滚动条也有预留空间。
  滚动条出现、宽度变化或窗口调整时自动重新限位，左侧和底部继续贴边。
- 气泡整体上移 40px，在常规底部位置让主气泡与角色头顶保持间距，继续遵循视口限位。
- 12 个可配置触发场景按相同台词归并为 7 组，每组使用一个标题台词框，最多 160 字并可换行。
  修改一组同步更新其关联场景。气泡只渲染标题台词和面板入口。
  自动跳过场景使用 `{seconds}`；已知用量场景使用 `{cost}`。
  预览区显示固定示例，视频上的气泡替换为实际数值。
- 默认台词采用用户批准的本机文案。文案版本为 4，旧版标题 / 说明迁为单标题，
  峰谷占位符迁为 `{cost}`，旧报错场景统一采用新报错台词。其他不同的历史自定义文案继续分别编辑；
  同组相同文案合并显示。空标题用于静默显示角色，重复读取保持迁移结果。
  Chrome 启动时写回迁移，油猴读取时迁移并在下次保存设置时写回 GM 存储。
- 本地 / 共享缓存命中固定为静默状态，对应台词配置已移除。旧配置在读取时清理；
  点击宠物显示待机台词，之后发生自动跳过时仍按自动跳过场景提示。
- 面板入口使用插件的彩色 Logo，按钮文字可编辑；提供单场景和全部台词恢复默认。
- 上传 PNG、JPEG 或 WebP（最大 10 MiB），在本机完整显示、缩放和拖动裁剪，
  输出 512×512 PNG。裁剪结果保存于扩展本机存储或油猴 GM 存储。
- 修改后自动保存并同步到已打开的视频页；失败保留对应字段供重试。
  普通单击触发摸头及音效，拖动专用于调整位置。长台词使用限高可滚动区域。

图片与台词保留在本机。浏览器实际验证与固定回归范围见
[宠物验收记录](testing/pet-preview-2026-10-08.md)。

## 默认台词

- 待机：「好模型...」
- 字幕读取 / 广告识别 / 本地转写：「恰饭片段寻找中...」
- 识别完成：「大肥鱼吃了你 ¥{cost}」
- 标记就绪：「恰饭片段已定位！」
- 自动跳过：「跳过 {seconds} 秒恰饭片段~ 吃点白饭不过分吧！」
- 统一报错：「搞不定啦！打开面板自己看一下~」
- 用量待确认 / 短视频豁免：留空。

## 单次参考费用

参考 DSH 小鲸鱼的 `lib/index.js` 计费逻辑，在收到 API 用量时按北京时间选择价档。
北京时间周一至周五的 09:00–12:00、14:00–18:00 为高峰，其余时段为空闲；
2026-08-23 起周末全天为空闲，2026-09-19 起中国法定节假日全天为空闲，调休工作的周末同样为空闲。
当前内置 2026 年节假日表，未来年份的潜在高峰工作日需先补齐节假日表，费用才能确定。

2026-10-08 核对的 Flash 人民币单价（每百万 token）：缓存命中 0.02 / 0.04、未命中 1 / 2、
输出 4 / 8（空闲 / 高峰）。输出 token 已包含推理 token，按输出总量计一次费用。
金额保留至 8 位小数，记录所选时段、用量时间和单价快照日期，之后的显示保持原金额。
历史记录使用记录中的价格对及原记录时间选择金额，并标明「按记录时间估算」。

这是单个本地参考估算，实际扣费以 DeepSeek 账户账单为准。当前日历缺失或历史时间缺失时，
面板显示费用待确认；宠物沿用用量待确认场景。
价格及规则来源：[DeepSeek 官方价格说明](https://api-docs.deepseek.com/zh-cn/quick_start/pricing)，
参考实现：[DSH 小鲸鱼](https://github.com/MeteorNOX/DeepSeek-Balance-Whale-Widget)。

## 本地构建

```powershell
node scripts/build-pet-assets.js
node scripts/build-pet-preview.js
# 可选指定其他本机图片。
node scripts/build-pet-preview.js 路径/角色.png
# 可选第三参数为本机参考音效目录，目录中包含 Ya1.mp3、Ya2.mp3。
node scripts/build-pet-preview.js 路径/角色.png 路径/参考音效目录
```

预览图为 PNG，最大 1MiB、2048×2048。图像以内嵌数据保存在本地预览产物中。
可传入其他透明 PNG 查看换肤效果。普通构建和预览构建都使用当前角色图及小黄鸭音效，
默认源文件位于 `assets/pet/`，按清单校验后内嵌到 `extension/pet-assets.js`，扩展与油猴共用。
「恢复默认图片」恢复这张角色图；两段默认音效 `Ya1.mp3` / `Ya2.mp3` 在完成单击后顺序播放。
