# Whisper-small WebGPU 语音识别实测

日期：2026-10-01。目标：验证浏览器 GPU 语音识别，并与现有 SenseVoice CPU 方案比较。
本轮新增独立 POC，正式扩展、提示词、共享缓存和部署保持原状。

## 结论

Whisper-small WebGPU 已在 Chrome 实际完成短片段和句级时间戳的全片转写。
本轮相同中文短片段的 SenseVoice CPU 耗时为 12.83 秒，Whisper GPU 为 42.16 / 46.37 秒。
现有 SenseVoice CPU 更适合当前默认方案；Whisper GPU 保留为实验备选。

这是一条视频、两种模型和不同运行时的方案比较。对同一个模型的纯 CPU/GPU 加速比需要另行测试。
结果只代表本机、本模型快照、指定精度、运行时版本与音频样例。

## 实测结果

测试机器：Ryzen 5 3600、32GB RAM、RTX 3080 12GB；Chrome 154，Playwright 操作同一浏览器。
音频为此前 `BV1pFUDBKE8X` 的 16kHz 单声道 WAV，全片 518.4551875 秒；短片段为原视频 150–215 秒。

| 方案                                             |   音频长度 |   识别耗时 | 倍实时 | 结果                                    |
| ------------------------------------------------ | ---------: | ---------: | -----: | --------------------------------------- |
| SenseVoiceSmall INT8 / WASM CPU，本轮重测        |      65 秒 |   12.83 秒 |   5.06 | 8 个语音段，32 条切句字幕               |
| Whisper-small / WebGPU / 词级时间戳              |      65 秒 |   42.16 秒 |   1.54 | 312 个原始词/字块，切句 v2 后 12 条字幕 |
| Whisper-small / WebGPU / 句级时间戳              |      65 秒 |   46.37 秒 |   1.40 | 37 条字幕                               |
| Whisper-small / WebGPU / 词级时间戳              | 518.455 秒 | 处理中异常 |      — | 运行时返回数值错误码，完整结果缺失      |
| Whisper-small / WebGPU / 句级时间戳              | 518.455 秒 |  336.55 秒 |   1.54 | 26 个窗口，229 条字幕                   |
| SenseVoiceSmall INT8 / WASM CPU，9月30日历史对照 | 518.455 秒 |  105.80 秒 |   4.90 | 89 个语音段，切句 v2 后 229 条字幕      |

表中识别耗时独立于模型下载、初始化、GPU 预热和音频解码。
本轮 CPU 短片段在 GPU 转写结束、卸载模型后执行，两项推理串行。
完整音轨 CPU 行来自历史 Chrome 实测，单独标注其日期；同样例 GPU 句级耗时约为它的 3.18 倍。

## 模型、下载与缓存

- 模型：`onnx-community/whisper-small_timestamped`，多语言。
- 固定 revision：`65caa70f294b46e1c33ff820aae6b16d048ab818`。
- Transformers.js 3.8.1；ONNX Runtime Web `1.22.0-dev.20250409-89f8206ba4`。
- 编码器 FP32、合并解码器 Q4；设备显式设为 `webgpu`。
- 固定中文 `language: "chinese"`、转写 `task: "transcribe"`、贪心生成。
- 音频窗口 30 秒，左右各 5 秒重叠，后续窗口每次前进 20 秒；每窗口最多 448 生成 tokens。
- 词级时间戳使用模型注意力 + DTW；句级时间戳使用模型生成的分段。

模型权重及配置总计 **590,613,194 字节，约 591MB**，本次公网准备下载用了 **32.80 秒**。
该时间包含最多 3 个并发文件下载，是当前本机网络的一次观测。
运行时 WASM 另约 21.6MB。资源均已放到本机，浏览器运行时从回环地址读取。
权重与上游 LFS SHA-256 核对通过，全部资源大小和哈希记录在 `dist/whisper-webgpu/model-assets.json`。

| 浏览器加载     | 模型读取/初始化 | GPU 预热 |     合计 | 缓存状态                        |
| -------------- | --------------: | -------: | -------: | ------------------------------- |
| 首次本机读取   |        11.00 秒 |  3.65 秒 | 14.65 秒 | 7 次缓存写入                    |
| 卸载后重新加载 |        19.83 秒 |  1.44 秒 | 21.27 秒 | 10 次命中、0 次未命中、0 次写入 |

缓存命中验证了模型资源复用。初始化耗时仍随磁盘读取、图优化、GPU 管线和系统负载变化；这两次观测分别保留。
本轮验证单页面卸载重载；多 Tab 任务调度与单实例共享属于后续集成验收。

## 显存与运行时

每约 1 秒执行一次 `nvidia-smi`，共 818 个样本：

- 初始整卡显存：1445MiB。
- 模型加载及预热后：约 3221MiB。
- 全测试整卡显存峰值：3614MiB，约 3.53GiB。
- 相对初始增量约 2169MiB，约 2.12GiB。
- 卸载后回到约 1.4GiB；峰值 GPU 利用率 86%。

这些是整卡观测值，包含桌面及其他应用，采样间隔可能遗漏更短峰值。
运行时日志提示部分辅助算子在 CPU 执行；端到端时间包含特征提取、生成、时间戳和 CPU/GPU 数据交换。

词级全片调用返回错误码 `489513456`。最后已观察到完成 7 个窗口、约 99.4 秒进度，随后停止。
原始失败报告和控制台保存完整。该次原始报告只含数值错误码，根因仍待进一步定位。
句级全片运行完成；该次成功与词级失败分别记录。

## 内容与边界检查

本轮广告识别模型调用为 0；以下仅观察 ASR 文字及时间戳。

### 可提取的广告线索

GPU 全片句级结果保留了转转、上门回收、全国 400 多个城市、一键下单等广告线索。
广告引入句单独位于 **167.16–168.96 秒**：

```text
先感谢本期视频的赞助上转转
```

原 B站字幕的对应引入起点为 166.94 秒；本轮 SenseVoice 短片段为 167.00 秒。
GPU 全片句级的“那我们说回正题”位于 203.92–205.00 秒，能与推广段落分开。

### 需要继续评估的问题

1. 常见词与专名均有错误，例如 Whisper 中的“前置物品”“赞助上”“写字了”。SenseVoice 同样有识别错误，应按下游广告区间质量评价影响。
2. GPU 短片段句级的约 174 秒位置出现重复拼接与 `�` 字符；原始文本按模型输出保存。
3. GPU 全片约 184.32–185.28 秒重复了前面的回收服务句子，导致较长文字挤在短时间段内。
4. 固定中文条件下，全片约 361–388 秒英文讲话出现语义失真和超长字幕块。多语言/混合语言检测需要单独处理。
5. 词级短片段基本没有标点，切句 v2 多依赖长度和停顿，广告引入与周边句子有混合。

因此，这轮结果证明浏览器 GPU 路径能够执行转写。当前默认选择继续以已验证的 SenseVoice CPU 为主。
后续若追求 GPU 提速，可优先评估 SenseVoice 的 WebGPU 运行时适配，或另测更适合中文的浏览器模型。
