# Qwen3.5-4B 非思考 POC 结果归档

测试日期：2026-10-01。归档范围：三条完整字幕、独立窗口检测、重叠候选合并、边界复核。
本文保存到仓库文档；完整请求、字幕、输出、截图留在本机 `dist/`。

## 配置与结果

- 模型：`Qwen3.5-4B-q4f16_1-MLC`，固定 revision `44b42469f9e192814bfd90440e3b377d89ba7a13`。
- WebLLM 0.2.85 / WebGPU；NVIDIA RTX 3080 12GB。
- 非思考，4096 上下文，512 输出上限，128 token 余量。
- temperature 0.7、top_p 0.8、presence_penalty 1.5、seed 42。
- 每窗口最多 7 分钟、重叠 30 秒，实际 tokenizer 验证预算；每轮重置会话。
- 候选按编号交集合并，使用前后约 60 秒上下文重新复核；保留全部评分。
- 每条视频各一轮，共 10 次调用；所有实际输入 token 数与计划一致。

## 关键观察

1. 三条初检均找到对应广告，两条完成全部检测与复核。
2. 流量卡第三窗口输出“正常推荐、评分 0.1”的五列行，随后输出 `NONE`，触发格式校验，尚未进入复核。
3. 腰靠第一窗口输出 `165–169 / 0.85`，第二窗口输出 `165–206 / 0.98`，成功合并。
4. 腰靠复核输出 `165–207 / 0.98`，相对参考留下 4.97 秒广告引入，多包含 2.88 秒恢复正文。
5. 后续验证重点：有界格式重试、复核前后边界误差、纯正文与主题产品介绍负样本。

流量卡格式错误的最终输出：

```text
549|552|法国戴高乐号航母 | 结尾处引导观众观看相关期视频作为正常推荐 | 0.1
NONE
```
