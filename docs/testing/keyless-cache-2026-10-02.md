# 空Key共享缓存模式

日期：2026-10-02。基于扩展0.1.8／油猴0.1.8.3本地试用源码，保留此前ASR任务锁拆分修复。

## 行为

- 页面准备阶段原有共享查询继续独立于DeepSeek Key和模型授权。
- 空Key或DeepSeek授权关闭时，弹窗显示缓存模式，主按钮改为「查询共享缓存」；共享查询关闭时显示「读取本地缓存」。
- 命中的广告／零广告结果通过原有视频身份、字幕哈希、编号和区间校验，继续用于进度条、跳过和撤销。
- 暂无匹配时显示稍后查询或配置Key自行识别的提示；主按钮走缓存准备入口。
- 已开启本地ASR且共享查询开启时，缺少字幕的视频提供「转写并查询共享缓存」。此操作由用户手动点击发起。
- 缓存转写流程在本机生成字幕并计算指纹，随后只查询共享结果；音频和完整字幕留在本机。
- 新字段`transcribeForCache`为可选布尔值，两端消息处理验证类型。模型调用继续使用原有独立授权链路。
- 页面轮询继续读取已有状态，自动DeepSeek分析保留Key和授权条件。模型下载、ASR和短视频豁免开关保持原值。

共享查询继续要求完整字幕身份匹配，命中范围由线上现有数据和输入指纹决定。
本轮提示词、缓存协议、权限范围和线上后端保持原样。
