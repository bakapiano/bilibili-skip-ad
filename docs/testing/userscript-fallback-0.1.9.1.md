# 油猴0.1.9.1：可选ASR资源降级

验收版本：扩展0.1.9，油猴0.1.9.1。

## 行为与边界

- 两个固定SRI资源分别为WASM、VAD/词表。首次需要新转写或下载模型时校验，字幕正常时保持惰性。
- 资源缺失、读取失败、长度或SHA-256异常、读取超过10秒时，暂停当前页面的新ASR任务和模型下载。音轨请求、解码和Worker创建均在资源检查之后。
- 失败状态在当前页面复用，避免自动反复请求；设置页显示原因和「重新检查资源」，成功后恢复入口。已校验的资源在当前页面复用。
- 保留用户保存的开关、239MB模型缓存、已转写字幕与广告结果。已有转写字幕的读取先于资源检查。
- 普通字幕、个人DeepSeek调用、本地和共享缓存、进度条、自动跳过、撤销均独立工作。转写上传偏好保持可修改。
- 本次覆盖已安装脚本的运行阶段；安装及更新资源仍由油猴管理器处理。保留固定SRI、运行时大小/SHA-256、域名白名单和本地data/blob读取限制。
- 提示词、ASR字幕版本、缓存身份和共享协议保持0.1.9的值。

## 共享服务故障路径

- 共享查询单次5秒超时；查询异常转换为提示，已有本地结果继续使用。
- 已配置Key并授权时，字幕路径仍可调用DeepSeek生成新结果。
- 自动上传先保存本地结果；上传失败保留本地标记，并记录失败回执以便手动重试。
- 空Key且无匹配本地缓存时显示提示，保留正常视频播放与设置操作。

## 固定回归

- `tests/userscript/asr-resources.test.js`：两个资源分别缺失、篡改、超时、晚到结果隔离、并发检查合并和显式恢复。
- `tests/userscript/runtime.test.js`：ASR失效时音轨和模型调用为0；资源状态保留，字幕恢复后完成分析/自动上传/本地复用；已转写字幕继续读取。
- `tests/userscript/bundle.test.js`：完整构建产物启动、设置控件、进度条、跳过、撤销、共享查询和SPA；共享503与ASR失效组合；资源恢复后入口恢复。

## 验收执行

- `npm run verify`：317项测试全部通过，ESLint、Prettier、扩展资源/CSP和凭据检查通过。
- `npm run build:userscript`：生成0.1.9.1，共713,034字节；业务与Worker JS完整包含在脚本内，两个固定SRI资源保持原值。
- 隔离Chromium中执行正式构建产物，使用合成的100秒原生WAV音轨、明确的GM/网络测试适配器和固定模型响应，外部网络请求全部拦截。
- ASR资源失效：字幕分析、自动上传及共享读取成功；原生媒体定位12秒自动跳至20.05秒，撤销回12秒。
- ASR资源与共享服务503同时失效：字幕仍可分析并保存在本地，标记和原生媒体跳过通过；主动线上查询后继续使用本地结果，模型请求保持1次。

- 无字幕且ASR资源失效：显示局部降级提示，视频继续正常播放；音轨、模型和Worker调用均为0。
- 使用实际固定WASM/VAD文件模拟管理器恢复，重新检查后入口恢复；恢复检查本身保持Worker调用0次。
- 页面异常0条、意外外部请求0条、真实付费模型请求0次。Tampermonkey管理器安装/更新阶段仍按单独流程验收。
