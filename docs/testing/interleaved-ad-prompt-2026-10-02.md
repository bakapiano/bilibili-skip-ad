# 广告之间穿插正文：提示词实验

日期：2026-10-02。视频`BV1eVaz6UENn`《【不是榨菜】击沉一艘航母有多难？》，519秒。
本轮仅实验，生产提示词、插件、线上记录和发布包保持原样。

## 固定输入与评判依据

从用户本机Chrome扩展IndexedDB的离线副本提取SenseVoice字幕，213条、3260字符。
重新normalize后的SHA-256与线上记录完全相同：
`c2d65dafa231bf510eebff246b64fd99787fda2dff4c01bd052cad603ad89351`。
保留原始ASR错字，全部实验均使用相同完整标题与编号字幕。

用户确认152–162句为正文，时间370.904–401.052秒，共30.148秒。
人工建议163句“除了作战体系”也跟随正文保留；建议广告为129–151及164–178。
实验提示词未提供这些人工正确答案、正文编号或品牌示例。
复核实验仅提供已存在的模型候选129–178，作为上一阶段输出。

模型和参数沿用生产：`deepseek-flash`，非思考，temperature=0，max_tokens=2048，stream=false。
每轮独立请求，原始输出、用量和请求内容均保存；共24次真实API请求。

## 结果

| 条件                             | 次数 | 用户确认的正文全部保留 | 广告范围表现                              |
| -------------------------------- | ---: | ---------------------: | ----------------------------------------- |
| 当前v5 prompt                    |    5 |                    0/5 | 全部129–178                               |
| 仅追加拆段与内部检查规则         |    5 |                    0/5 | 全部129–178                               |

| JSON复核＋引入短句归属规则       |    3 |                    2/3 | 两次130–151、164–178；一次额外误标154–156 |

前18轮维持生产的五列输出协议。前三种修改累计13轮均继续把正文并入大区间。
结果说明这些措辞对本视频的非思考单轮识别没有产生可用改善。

后6轮改变工作方式及输出协议：先显式生成`body_ranges`，再生成`ad_ranges`。
它们能识别中间存在独立正文，但仍有边界错误和稳定性问题：

- 第一版3次都误含152句“从消防损管系统来看”，1.560秒。
- 第二版2次避开用户指出的152–162；另1次误将154–156归为游戏推广，覆盖约7.740秒。
- 两版共6次`body_ranges`都额外列出了候选之外的179–208，违反该实验要求的范围。
- 第一段起点多为130，仍与人工建议129有一条引入句差异。

因此“正文保留2/3”仅是专项指标，不能解释为整份输出验证通过。
显式复核同时改变提示词、附加候选信息、输出格式，改善原因需要进一步拆分实验。
