# 0.1.4 工具栏弹窗与自动上传回归

日期：2026-09-29。

## 行为

- 操作面板位于 `action.default_popup` 指向的 `popup.html`。B站页面保留原生时间轴广告标记与隐藏诊断节点。
- 弹窗通过 `BILISKIP_CONTROL` 读取页面状态、分析、读取本地/线上缓存、切换自动跳过、跳过、撤销、试听和手动上传。
- 页面控制器校验扩展 ID、弹窗 URL、视频路由、记录版本和区间编号；视频切换后更新状态。
- 弹窗关闭后页面控制器与后台任务继续执行；弹窗的状态轮询停止。
- 新分析结果保存本地后自动上传一次，`autoUpload` 默认开启，可在设置中关闭；`sharedUpload` 保留全部上传的总开关。
- 缓存命中复用结果。上传失败保留本地标记、错误回执和手动重试入口。模型等待期间更改上传开关，在上传前按最新设置执行。

## 自动化验证

`npm run verify`：129 项测试（含子用例）、ESLint、Prettier、扩展静态检查通过。

- 播放回归保留原有跳过、重复定位、撤销、低置信度保护、媒体加载和 SPA 切换用例。
- 弹窗真实运行脚本在确定性 DOM 中验证全部按钮、语言、标记、统计、忙碌状态、断连提示、来源校验与过期响应隔离。
- 设置真实运行脚本验证自动上传默认值、关闭保存、重新打开保留，以及上传总开关关系。
- 自动上传用例覆盖成功、0 段广告、缓存命中、无效模型结果、权限不足、429/409/503、重试幂等和途中关闭。
- 本机 HTTP + SQLite + IndexedDB 集成用例验证新分析结果自动入库，并由第二个客户端命中；模型与字幕为明确标识的固定测试数据。
