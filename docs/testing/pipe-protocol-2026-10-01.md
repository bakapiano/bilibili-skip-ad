## 实现

输入只保留标题和 `ID|正文`。输出为 `起始ID|结束ID|品牌|简短说明|评分`，零广告为 `NONE`。
模块位于 `extension/lib/prompt.js` 与 `extension/lib/model-output.js`，Chrome、油猴、Qwen POC 共同复用。
DeepSeek 继续使用 `deepseek-flash`、非思考、temperature 0、单次输出上限 2048；移除 JSON 模式要求。
Qwen 继续使用 4K 预算与原模型，生成五列文本并经过同一严格解析器验证。

视频身份与字幕哈希由请求发起时的本地快照绑定；时间戳保留本地。解析器校验格式后再通过原有区间校验。
内部记录继续保留 `summary`（程序汇总）、`reason`（模型简短说明）、空的 `evidence_ids` 和证据列表。
共享服务接受 `ad-cues-v1`、`ad-cues-v2-compact` 和 `ad-cues-v3-pipe`，缓存身份按版本隔离。
新增空证据协议有独立测试，其他编号、时间、身份和每 IP 每秒一次限流继续保留。

## 费用比较

2026-10-01 16:13 北京时间重新读取官方 [模型与价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing)：
Flash 空闲时段每百万 token 为输入命中 0.02 元、未命中 1 元、输出 4 元；高峰价格均为两倍。
以下以 API 实测用量乘空闲价估算，扣费以实际账单为准。

| 口径                                     |   最初 JSON |  标题＋五列 |                       降幅 |
| ---------------------------------------- | ----------: | ----------: | -------------------------: |
| 同等全冷输入，三轮平均估算               | ¥0.00805367 | ¥0.00266233 |                  **66.9%** |
| 第二、三轮均有缓存命中，按实际命中量估算 | ¥0.00133868 | ¥0.00027364 |                  **79.6%** |
| 第一轮按实际命中量估算                   | ¥0.00153868 | ¥0.00267300 | 旧请求热缓存，新请求冷缓存 |

同等全冷口径，每个视频约省 **0.00539 元**，每 1000 个此类视频约省 **5.39 元**。
本次六次测试合计约 **0.00744 元**（按实际命中量和空闲价估算）。
格式收益、缓存命中收益分开呈现；第一轮原始缓存条件保留在表中。

### Qwen 真实 Chrome 154：发现质量回归

在独立 Playwright 会话、RTX 3080 12GB、本地 Qwen3-4B Q4F16 上测试三次：

1. 五列 grammar、原字幕、默认7分钟窗口：两次检测均生成 `NONE`，漏掉参考广告。
   累计输入3727、输出2 tokens，耗时8.77秒。格式与预算通过，语义结果判为失败。
   报告：`dist/asr-poc/qwen-reports/2026-10-01T08-16-52-403Z-2d89de2d.json`。
2. 普通文本、同一原字幕和默认窗口：仍生成 `NONE`，说明本样例无法将漏检仅归因于 grammar。
   报告：`dist/asr-poc/qwen-reports/2026-10-01T08-19-40-015Z-bf040d43.json`。
3. 普通文本、完整ASR字幕、3分钟窗口：第一段输出包含重叠编号，如75–76和76–77。
   实际校验器以“广告时间段发生重叠或越界”暂停识别，未生成可用的广告记录。

较早 JSON 输出实验能够找到广告，但存在边界偏差，见 [上一轮记录](compact-prompt-2026-10-01.md)。
当前五列 Qwen POC 标明质量风险，继续作为实验版本。后续需要独立调整小模型提示词或输出策略并扩大测试样本。
正式版 DeepSeek 使用本次三轮全部通过的结果，其质量和成本结论与 Qwen 实验分别呈现。
