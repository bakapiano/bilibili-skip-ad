# 0.1.9 本地ASR试用

Chrome扩展版本`0.1.9`，油猴版本`0.1.9.0`。本次交付为本地试用包。

## 设置

- **本地语音转写**：默认关闭，用户按需开启。并发可选1、2、4、6、8，默认2。
  升级保留已有明确保存的开关值；曾在早期试用版保存开启状态的用户可在设置中关闭。
- **上传转写字幕用于准确度评估**：默认开启，独立于广告标记上传开关。新转写结果完成后上传视频信息、完整字幕及时间戳、ASR／客户端版本；音频在本机处理。关闭后保留本地处理，已缓存字幕读取沿用已有记录。
- **短视频豁免**：独立section，包含开关、分钟数和范围说明。默认关闭，预设3分钟。
  分钟数范围0–180，输入步长0.1；严格按 `视频秒数 < 分钟数 × 60` 判断。
  开启后，符合条件的视频仅获取基础信息，直接保留完整播放；字幕获取、ASR、
  广告识别、广告缓存应用和跳过全部豁免。手动强制分析也遵循该规则。
- **进度条**：只画达到当前评分阈值且通过累计广告时长保护的区间。
  阈值默认0.90，累计广告时长须小于全片50%。试听、撤销保留的片段同步隐藏。
  调整阈值后标记即时更新；面板保留全部识别结果供人工核对。
- 自动分析与自动跳过仍采用原设置，首次默认关闭。
- **缓存模式**：空Key或DeepSeek授权关闭时，直接复用本地／共享结果。已开启本地ASR且共享查询开启时，主按钮提供「转写并查询共享缓存」；此操作手动发起、仅用于取得查询指纹，模型调用数为0。暂无匹配标记时可稍后查询或配置Key自行识别。

### 提前下载模型

在“本地语音转写”区块点击“下载模型”，进度条显示百分比、下载字节和校验阶段。
下载源可选BiliSkip本站、HF-Mirror镜像、Hugging Face原站，默认本站。
点击下载立即使用当前选项；保存设置后，自动转写也沿用所选源。
Chrome对第三方源按需请求相应域名及已审查CDN的可选权限，油猴声明相应精确`@connect`域名。
镜像和原站可能重定向到同一个Hugging Face CDN，实际连通性和速度取决于网络。
下载独立于ASR开关及DeepSeek授权，可提前完成准备；ASR默认关闭的设置保持原值。
下载时保持Chrome设置页／油猴设置面板打开，可以点击“取消下载”。中断后重试从头下载。
完成后显示“模型已缓存并通过校验”；再次打开设置页自动检查缓存，按钮变为“校验已缓存模型”。
提前下载仅写入模型磁盘缓存，CPU转写Worker在实际转写时才创建。
不同页面的模型准备通过Web Locks互斥，避免重复下载同一大文件。

## 处理链路

1. 获取BV、分P、CID和时长，检查短视频豁免。
2. 按中文、英文、其他语言依次尝试站内字幕。
3. 全部轨道为空时，先查询本地ASR字幕缓存。首次转写由显式分析或已授权的自动分析触发，
   并提前检查DeepSeek Key及字幕发送授权。
4. 下载当前视频AAC音轨，在浏览器解码为16kHz单声道。
5. CPU运行Silero VAD和SenseVoiceSmall INT8，按词级时间戳切句、排序和校验。
6. 按字幕指纹查询广告缓存，随后根据需要请求DeepSeek，继续复用已有校验与跳过流程。

ASR首版支持60分钟以内、下载体积64MiB以内的音轨。字幕接口故障保留原错误供重试。
转写期间改为豁免，会在DeepSeek请求前重新核对；已发出的请求可能已经产生用量。

## 模型与资源

Chrome的运行JavaScript、WASM、Silero VAD与词表随包分发。油猴业务JS随脚本分发，
WASM与VAD/词表通过带固定SRI的`@resource`从本站预加载。主模型按需下载：

- SenseVoiceSmall INT8，239,233,841字节，约239.2MB。
- 上游来源：Hugging Face的csukuangfj转换仓库，固定revision
  `2365baeacb507f821a0c8120fcee3d484dba7a07`。
- 默认下载：`biliskipad.bakapiano.com/models/sensevoice-small-int8/<sha256>.onnx`，本站原样镜像。
- 另外提供HF-Mirror与Hugging Face原站选择，均定位到同一revision的`model.int8.onnx`。
- SHA-256：`c71f0ce00bec95b07744e116345e33d8cbbe08cef896382cf907bf4b51a2cd51`。
- 下载统一使用匿名请求；本站固定地址拒绝重定向，镜像/原站允许已审查的Hugging Face CDN目标。各源每次完整下载均核对239,233,841字节与相同SHA-256。
- Chrome安装时保留本站权限，第三方模型下载权限按需申请。旧URL缓存先验证再本地迁移，所有源共用本站URL这一规范缓存键。
- 模型缓存名 `biliskip-asr-model-v1`。检测到哈希异常的缓存会移除并提示重试。
- 每路WASM线性内存约512MiB；默认2路约1GiB，模型副本、音频解码、JS与浏览器内存另计。
  任务完成或失败后终止Worker池，后续任务复用磁盘模型缓存并重新加载。

语音模型保持SenseVoice/FunAudioLLM作者归属；第三方许可见
[`extension/asr/vendor/NOTICE.md`](../extension/asr/vendor/NOTICE.md)。
模型条款与BiliSkip自身MIT许可分别适用。

## 两个平台

Chrome使用单个offscreen页面管理CPU Worker池；后台按视频复用在途分析，同一扩展的
多个标签页共用模型缓存与IndexedDB转写记录。ASR与DeepSeek分别独占各自资源；
ASR进行期间，其他有普通字幕或已缓存转写字幕的视频可以继续分析。已有广告标记可直接读取。
同类资源忙碌时提示重试；同一视频的重复分析继续复用在途任务。
新增`offscreen`、`unlimitedStorage`及`declarativeNetRequestWithHostAccess`权限：
最后一项仅为扩展发往B站媒体CDN的请求添加B站Referer，以取得当前播放权限对应音轨。

油猴复用同一个ASR引擎，Worker源码保留在脚本中，WASM和VAD/词表由油猴管理器预加载并校验SRI。
运行时读取管理器本地资源并复核SHA-256。转写字幕保存在GM存储，
模型保存在B站origin的CacheStorage，同源标签页通过Web Locks分别保护同视频任务、ASR、模型请求与上传。
页面关闭或刷新会停止本页任务。Chrome、油猴、其他浏览器配置分别保存缓存。
目前油猴文件约708KB，安装时需要额外准备约12.5MB固定资源，主模型约239MB仍可在设置页主动下载。

## 数据流与兼容

音频留在浏览器处理，转写后的标题与字幕按现有授权发送给DeepSeek。
模型按所选源从本站Nginx、镜像或原站及其CDN下载，相应服务接收必要网络连接信息。本站模型文件独立于共享数据库和IP提交限流。
API Key和B站会话继续留在各自认证链路。

提示词升级为`ad-cues-v6-json`，沿用标题＋编号字幕输入，输出改为仅广告JSON v2。
旧Key、设置和标记保留；广告缓存按新提示词命名空间重新积累。
IndexedDB自动升到版本2并增加`transcripts`，普通缓存清理也清理转写记录。
模型文件的CacheStorage独立保留，可通过浏览器存储管理清理。

共享后端已于2026-10-01部署v1–v5兼容，试用包可直接使用线上查询和自动上传。
原有158条缓存逐条核对保持原样；以本次真实ASR/DeepSeek结果验证v5上传201、查询200、重复提交200。
本次后端更新保留官网与公开下载包原样，详见 [后端部署记录](../server/DEPLOYMENT.md)。
