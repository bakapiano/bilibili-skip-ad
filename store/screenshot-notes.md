两张图片均在真实 Chrome、实际 B站视频页面和已加载的 BiliSkip 扩展上截取。

测试视频：`BV1pFUDBKE8X`。截图使用既有本地缓存，拍摄过程沿用已有标记。
图片经过格式规范化，保留原始界面像素和内容；标题、按钮、识别结果均来自真实运行状态。
素材不包含浏览器标签栏、地址栏、账号菜单、搜索历史或 API Key。

视频中的第三方画面及标识归其权利人所有。发布者应确认这些画面在商店截图中的使用权限；可按相同流程替换为已授权视频截图。
