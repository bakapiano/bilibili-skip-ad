# 隐私与权限字段填写草稿

此文件供发布者填写开发者后台时核对。事实依据为版本 `0.1.4` 的代码和数据流；认证声明由发布者结合实际运营确认。

## 单一用途

根据 B站视频字幕识别视频内的商业植入，在播放器时间轴标记广告区间，并根据用户设置执行跳过、试听和撤销。

## 权限说明

| 权限或域名                   | 用途说明                                                                                                                            |
| ---------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| `storage`                    | 保存个人 DeepSeek API Key、可选共享令牌、用户设置与扩展运行状态。广告标记和字幕上下文保存于 IndexedDB。                             |
| `https://www.bilibili.com/*` | 在标准视频页运行播放器控制器，读取当前视频身份，标注时间轴并响应工具栏弹窗操作。                                                    |
| `https://api.bilibili.com/*` | 获取视频元数据和字幕轨道，验证 BV、分 P、CID 与时长。浏览器按站点规则附带用户已有登录态。                                           |
| `https://*.hdslb.com/*`      | 下载 B站字幕 CDN 提供的字幕文件。                                                                                                   |
| `https://api.deepseek.com/*` | 经用户授权，使用其个人 API Key 提交当前视频标题、视频信息和字幕，接收广告区间 JSON。                                                |
| 可选 `https://*/*`           | 用户可填写自己的 HTTPS 共享服务域名；开启对应功能时申请该具体域名的主机权限。用于共享标记查询，以及依照上传开关进行自动和手动上传。 |

## 数据类别核对

固定域名权限 `https://biliskipad.bakapiano.com/*`：默认查询共享标记，发送视频标识、字幕指纹及模型版本；新分析结果默认自动上传视频信息、广告标记和有限证据，设置中可单独关闭自动上传，并保留手动上传入口。服务记录来源 IP（IPv6 按 /64 网段）、UTC 日期和计数，逻辑保留 7 个 UTC 日期。上传标记保留供共享查询和维护者复核。

官方披露范围包含本机处理和本机存储。请按后台当前类别及下列事实核对：

- 身份验证信息：DeepSeek API Key、可选共享服务令牌。本机保存，分别用于向对应服务认证。B站的登录态由浏览器管理。
- 网站内容：当前视频标题、分 P 标题、字幕、广告证据和模型标记。
- 网页浏览记录相关信息：当前分析的视频标识和标题会进入本地缓存，并随分析请求发送给 DeepSeek；请据后台定义判断对应类别。
- 用户活动相关信息：本机记录分析任务、模型调用、缓存命中、耗时、用量和错误类别；请据后台定义核对该类别。

API 使用量和费用显示为调用统计与参考估算，支付由用户在 DeepSeek 的账户中管理。

## 代码执行与数据使用说明

全部 JavaScript 随扩展包提供，模型响应按 JSON 数据解析、校验并映射为字幕时间。
数据用途围绕字幕识别、播放控制、本地缓存、默认共享查询及依照用户设置进行的自动与手动上传。
当前扩展运行代码中的网络目标为 B站接口、B站字幕 CDN、DeepSeek、内置线上缓存及用户配置的自定义共享服务。

请发布者核对后台的数据销售、用途限制与有限使用声明，确认与实际运营一致后勾选。

## 发布前待核对的安全事项

1. 当前源码将 Key 和共享令牌直接写入 `chrome.storage.local`，并限制到扩展可信上下文。请核对商店对静态数据加密的要求及实际保护方式，必要时完善存储方案后更新发布包。
2. 模型授权说明位于设置页；B站元数据与字幕可在页面准备时读取并保存在本机，隐私政策应覆盖此行为。
3. 隐私政策需部署成可公开访问的页面，并核对维护者、联系渠道、保留时间及第三方处理说明。
4. 可选广域主机权限用于自定义服务，需完整说明按域名申请的实际行为和默认关闭状态。
