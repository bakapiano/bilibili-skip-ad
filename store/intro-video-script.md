## 完整口播

搓了一个小插件，用 DeepSeek 识别并跳过 B站视频里的恰饭片段。油猴版可以从简介里的 Greasy Fork 链接直接安装，Chrome 商店已经上架，可以直接安装，Edge 商店还在审核，也可以先用 ZIP 安装。

填好 DeepSeek 的 API Key、确认字幕发送授权，再打开自动分析，插件就会先查缓存，需要识别时，把视频字幕交给 DeepSeek V4.1 Flash 分析。找到的恰饭片段会标在视频进度条上，开启自动跳过后，播放到这些位置，或者手动点进广告，都能跳到片段末尾。之前测的八分三十九秒视频，首轮识别大概花一两分钱。

同时也接入了在线共享数据库，大家可以复用已经识别过的结果，随着用户增多、共享数据不断积累，缓存命中率也会提高。

这个项目调研参考了小电视空降助手、bilijump-ai、biliadskip 和 bilibili-ai-subtitle，感谢这些项目的作者。插件官网、GitHub 和参考项目链接都会放在简介里，欢迎下载使用，也欢迎提 Issue、交 PR，一起完善。

## DeepSeek V4 Pro 改稿记录

实际通过官方 API 调用了 `deepseek-v4-pro`。第二轮提供演示结构，第三轮按用户反馈润色中文；之后用户进一步确认了“搓了一个小插件”的最终口播，上方采用用户确认版本。此前事实复核要点如下：

- 开场明确写成“广告末尾”，画面定位到具体广告片段。
- 缓存价值表述为“已有标记直接复用”，结合真实请求计数展示。
- 将 Key 的作用说明为调用 DeepSeek 的个人凭据；58 秒是分镜目标，录制前按实际语速试读。
