BiliSkip

隐私政策

适用扩展版本：0.1.4 · 草稿更新日期：2026 年 9 月 29 日

发布草稿：请维护者核对实际数据保护措施、联系渠道及第三方服务安排，完成存储安全审查后确认并公开部署本页。

1. 项目与适用范围

BiliSkip 是根据 B站字幕识别商业植入、标记广告区间并辅助跳过的 Chrome 扩展。本政策说明扩展处理的数据、用途、保存方式和用户控制。

项目维护者为 bakapiano。项目与联系渠道为 GitHub 仓库及其 Issues 页面。反馈时请仅提供排查所需的脱敏信息。

2. 处理的数据及用途

  • 视频与字幕：当前视频的 BV 号、分 P、CID、时长、标题、字幕文本及时间戳，用于识别当前视频、分析广告和映射广告边界。打开视频页面时可读取并缓存这些信息。
  • 认证与设置：你输入的 DeepSeek API Key、可选共享服务令牌、服务地址、授权状态和播放设置，用于连接你选择的服务和执行你的配置。
  • 识别结果：广告区间、品牌、理由、证据、自评分、字幕指纹与模型版本，用于显示、缓存、跳过和导出。
  • 本机运行记录：分析任务、缓存命中、调用用量、参考费用、耗时、时间和错误类别，用于展示状态、恢复中断任务与排查问题。

3. 向哪些服务发送数据

B站：扩展从 B站接口读取视频和字幕信息，并从其字幕 CDN 下载字幕。请求依照浏览器的站点规则使用已有登录态。

DeepSeek：在你配置 Key 并确认字幕发送授权后，分析请求通过 HTTPS 向 DeepSeek 发送当前视频信息、标题、字幕、字幕指纹及广告识别指令，API Key 用于该请求的认证。你可以分别选择手动分析或开启前台自动分析。第三方的处理和保留规则以该服务提供商的政策和你的账户安排为准。

线上共享服务：默认服务为 biliskipad.bakapiano.com，由本项目维护者运营。默认查询发送视频标识、字幕指纹及模型版本；新分析结果保存本地后默认自动上传标记、视频信息和有限证据句，工具栏弹窗也提供手动上传入口。自动上传可在设置中单独关闭，共享上传总开关约束自动和手动上传。服务记录来源 IP（IPv6 按 /64 网段）、UTC 日期和提交计数，计数逻辑保留最近 7 个 UTC 日期；上传标记保留用于共享查询，维护者可撤销。备份及基础设施日志的保存策略需由运营者另行核对。你可在设置中关闭共享或配置自己的服务；独立共享令牌按域名绑定，用于对应服务的认证。

网络服务会接收完成连接所需的网络信息，例如 IP 地址。扩展的网络请求围绕以上功能进行。

4. 本机保存与保留时间

API Key、共享令牌和设置保存在 chrome.storage.local，源码将访问范围限制为扩展可信上下文。字幕、标记、任务和候选队列保存在当前浏览器的 IndexedDB。使用记录仅保留最近约 200 条。

标记、字幕、设置与任务记录可保留到你进行相应清理或卸载扩展。它们位于你的浏览器配置文件中，本机账户、浏览器和设备的安全措施影响其保护。第三方收到的数据依照其服务规则处理。

5. 你的控制方式

  • 在设置页关闭自动分析、自动跳过、共享读取、自动上传或共享上传总开关，并调整字幕发送授权。
  • 在设置页清除 DeepSeek Key，或在提供商控制台撤销相应凭据。
  • 删除单条广告标记，或清空本地标记、字幕缓存和候选队列。该操作保留设置及近期任务、事件记录。
  • 将广告标记导出到本机文件，自行管理导出后的副本。
  • 卸载扩展以清理其浏览器专属存储。已经发送给第三方的数据和已导出的文件，由相应服务或你另行管理。

6. 安全与用途

扩展通过 HTTPS 与外部服务通信，使用字段校验处理字幕、模型结果和共享数据。模型结果作为 JSON 数据使用。凭据仅在对应服务认证时发送。

当前功能的数据用途为广告识别、播放辅助、本地缓存和你启用的共享操作。请谨慎选择共享服务，使用专用额度 Key，并保护自己的电脑和浏览器账户。

7. 更新与联系

功能或数据处理方式变化时，维护者应同步更新本政策及扩展内的授权说明。有关数据处理的问题可通过项目 Issues 联系维护者；涉及凭据时请先脱敏，再提交公开反馈。
