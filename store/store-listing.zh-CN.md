# 商店介绍文案

## 名称

BiliSkip · AI 广告跳过

## 简短说明

读取 B站字幕，通过个人 DeepSeek API 识别视频内广告，在进度条标记区间并按需跳过，结果保存在本地。

## 详细说明（复制到商店描述）

BiliSkip 根据 B站视频字幕识别商业植入，让你在观看前了解广告位置，并自主决定如何跳过。

主要功能：

• AI 广告识别：使用你配置的个人 DeepSeek API Key，结合完整字幕识别赞助口播和商业推广片段。
• 时间轴标记：在原生播放器进度条上，以金色区间显示识别到的广告。
• 按需自动跳过：开启后，播放或主动定位到符合评分阈值的广告区间，会跳至广告末尾。
• 试听和撤销：先试听广告边界；跳过后也可以撤销，继续查看原片段。
• 本地缓存：识别结果保存在当前浏览器，重复观看可复用已有标记。
• 跟随视频切换：处理侧边推荐视频和分 P 切换，更新对应视频的标记。
• 工具栏弹窗：点击 Chrome 工具栏的 BiliSkip 图标查看广告详情、分析、试听和撤销，视频页保持原生布局。
• 自动共享：新分析结果保存本地后默认上传共享缓存，设置中可单独关闭自动上传。

开始使用：

1. 在扩展设置中填入个人 DeepSeek API Key。
2. 阅读并确认将当前视频标题和字幕发送至 DeepSeek 的授权。
3. 打开 B站视频，点击 Chrome 工具栏的 BiliSkip 图标，再点击弹窗中的「分析当前视频」。
4. 试听边界后，根据需要开启自动跳过。

使用前请了解：

• 广告识别需要视频具备可获取的带时间戳字幕。字幕准确度、覆盖范围和模型判断会影响识别结果。
• DeepSeek 模型调用由服务提供商按用量计费，费用由你自己的 API 账户承担。重新分析会产生新的模型用量。
• 评分为模型自评，建议结合试听确认边界。
• 自动分析和自动跳过初始关闭。线上查询和新分析结果自动上传默认开启，设置页提供独立开关，弹窗保留手动上传入口。
• 当前主要流程为本地缓存、线上共享缓存与个人 DeepSeek 分析相结合，设置页可以关闭共享功能或配置自定义服务。

数据说明：个人 Key 和设置保存在本机扩展存储，广告标记、字幕上下文和近期任务记录保存在本机浏览器数据库。分析时，视频标题、视频标识和字幕发送至 DeepSeek。默认共享服务为 biliskipad.bakapiano.com，查询发送视频标识、字幕指纹和模型版本；自动与手动上传发送视频信息、标记和有限证据。服务记录来源 IP 及提交次数，逻辑保留最近 7 个 UTC 日期。

BiliSkip 是独立项目，项目维护和用户反馈通过 GitHub 仓库进行。
