# BiliSkip Prompt 评测环境

本目录集中维护数据整理、社区采集、本机服务、DeepSeek批次运行、时间区间指标、回归对比、界面和测试。
生产字幕处理、五列模型协议和播放器规则直接复用`extension/`中的模块。

## 启动

在仓库根目录执行：

```powershell
npm run prompt
```

浏览器访问`http://127.0.0.1:43820/`。`npm run lab`保留为相同入口。
使用Node.js 22.13+的22.x或Node.js 24+，首次安装依赖运行`npm ci --ignore-scripts`。

API Key可以在页面填写，或通过进程环境变量`DEEPSEEK_API_KEY`提供。Key只用于本机内存与DeepSeek鉴权。
命名Prompt、样本和运行快照均与凭据隔离。页面刷新后，进行中的批次继续由本机服务执行。
端口可用`BILISKIP_LAB_PORT`设置；样本目录可用`BILISKIP_LAB_DATA`设置。

## 使用流程

1. 首页以测试集展开：全部社区对照、社区固定1000条、社区随机采集、扩充随机采集、历史回归集、全部字幕输入。卡片展示总数、有效数、已移除数。
2. “测试集结果”选择批次查看整体指标和差异列表；“样本管理”可筛选有效/已移除样本、搜索并分页查看。
3. 点击样本或“调试 / 查看差异”进入“样本调试”。左侧编辑Prompt，右侧展示相同字幕输入的历史实验、区间与字幕。
4. 可载入任一实验Prompt继续修改，再点击“运行当前样本”。也可从测试集主页点击“测试整个有效集”，或在样本管理中测试勾选样本。
5. 核对调用数、选择重复次数和1–8路模型并发，勾选字幕发送与计费确认；超过20次调用时输入准确总数。
6. 该样本历史实验下可选择基线/候选，仅比较当前样本。整集对比位于“新旧Prompt对比”，使用相同测试集和有效名单。

页面默认进入测试集结果，完整字幕和单样本调试按需展开。地址栏记录测试集与批次，刷新后可以继续查看。

顶栏“问题样本”直接显示当前批次带原因标签的结果数量，点击一次即可查看原因标签和两行说明。
“有原因标签”“正文保护违例”“全部结果”提供平铺快捷筛选。顶栏随滚动保持可见，
从样本调试返回会回到问题列表；`workspace=issues`在刷新后恢复该视图。

## 移除原因与有效名单

样本列表、差异列表和调试详情均提供“移除”操作；填写具体原因并确认后，样本从有效测试集排除。
在“样本管理 → 已移除”查看原因和时间，通过“恢复”重新加入，恢复原因同样必填。

- 移除按BV/P/CID/字幕哈希标识同一输入，在该输入所属各测试集中一致生效。
- 原始字幕、社区参考、模型运行JSON保持原样，资格与完整变更历史单独保存在`prompt/data/exclusions.json`。
- 移除后本地重算所选批次指标；“原始运行名单”可查看该测试集范围内的原始计分。所有详情继续可读。
- 新旧批次读取同一份名单快照，明确列出排除数量与原因。页面显示每批覆盖了多少有效输入，以及批次计划中尚缺的结果。
- 新模型批次在发送前拒绝已移除样本，并保存名单版本；其他页面修改了资格后需刷新再提交。
- 活动模型批次期间暂停修改资格。已移除样本可查看历史调试结果，恢复后可再次运行。
- 大批次中其他样本失败时，已完整执行的单样本仍可独立对比；被取消、被中断、缺失或所选样本本身失败的比较继续显示未完成验证。

先依据字幕与原片确认标注问题，再填写移除原因；指标变化与移除数量一起查看。

单个批次的三个指标下方提供“差异较大样本”列表，每页10条，可按额外标记秒数、正文误跳率、
遗漏秒数、广告遗漏率或IoU排序，并搜索标题/BV/品牌。类型筛选包含已有复核线索、正文保护违例、
50%保护、低分区间、模型零广告与格式失败。
点击“查看差异”会展示所选批次原始模型区间、实际跳过、参考区间、额外/遗漏时间轴、原始回复和请求快照。
字幕先核对视频身份与本轮输入哈希，再展示差异前后3秒内的字幕及完整字幕折叠项；每个区间均可跳转原视频。
地址栏的`?run=<批次ID>`支持刷新后重新载入该批次，`#outliers`定位差异列表。
首轮基线的10条复核说明在`observations.js`按批次ID和Prompt哈希绑定，仅作为阅读线索。

停止会取消当前等待并阻止继续调度，已发送请求可能计费。HTTP 401/402/403/429会停止当前模型批次。
模型默认`deepseek-flash`、非思考、temperature 0、输出上限2048 tokens。并发和重复次数独立记录。

## 三项指标

对每个视频，先按播放器原始规则生成实际自动跳过区间：

- 片段评分`≥0.90`。
- **所有原始预测区间的累计时长**达到视频的50%时，自动跳过区间为空。
- 原始预测、实际跳过区间和保护触发状态均保留。

参考广告区间先合并为时间并集，避免重复计数：

| 指标       | 单视频定义                            | 总览口径                            |
| ---------- | ------------------------------------- | ----------------------------------- |
| IoU        | 预测与参考交集时长 / 并集时长         | 对参考广告时长大于0的视频逐例取平均 |
| 正文误跳率 | 超出参考广告的预测秒数 / 正文总秒数   | 全批累计误跳秒数 / 全批累计正文秒数 |
| 广告遗漏率 | 参考广告中未覆盖秒数 / 参考广告总秒数 | 全批累计遗漏秒数 / 全批累计广告秒数 |

正文总秒数=视频时长−参考广告并集时长。分母为0时显示`—`。
人工确认零广告样本进入正文误跳统计，并独立检查新增误跳；其IoU不计入正样本均值。
缺少社区参考只表示当前无法计算社区一致性，该状态单独计数。

完整人工标注优先于社区标注。部分人工复核仅提供明确正文保护区，继续保持独立保护含义。
社区集展示的是“按参考标注估算”，适合发现Prompt变化；人工确认案例用于质量与安全回归。
失败或取消的调用显式计数，批次最终标记为`partial`或`cancelled`。

## 回归判定

每次运行保存实际请求、标题和字幕指纹、参考区间/正文保护区快照、模型返回型号、参数及指标版本。
逐视频按BV/CID/字幕指纹/轮次配对，输入、参考及模型设置全部一致后才纳入配对指标。
样本缺失、执行失败、取消、重复结果或版本不匹配会使对比标记为“未完成验证”。

初版检查规则：

- 已确认正文保护区新增覆盖，或人工零广告视频新增误跳：硬回归。
- 候选仍覆盖明确正文保护区或误跳人工零广告视频时，保持阻断状态。
- 单例新增误跳正文超过2秒、广告遗漏率上升超过10个百分点、IoU下降超过5个百分点：进入必审清单。
- 整体IoU下降或任一错误率上升：提示复核。
- 指标通过表示相同参考标注口径下的比较通过。多次重复试验按同一轮次配对，完整保留各轮结果。

历史旧批次继续可读；完整输入与参考快照满足新指标身份要求的批次参与新旧判定。
单条详情可以直接查看历史模型在当前参考下的指标。

## 本机接口与安全

服务固定监听`127.0.0.1`，精确校验Host、Origin及随机会话令牌。所有外部文本使用`textContent`渲染。
模型调用目标固定到DeepSeek；API Key通过输入框发送至本机服务后留在批次内存。
网页GET仅可读取白名单静态资源和本机评测接口，目录内的数据文件通过验证后的ID访问。
活动批次期间字幕和人工参考保持冻结，原始请求与标注快照用于跨版本复现。

主要入口：`GET /api/cases`、`GET /api/case/<id>`、`GET /api/runs`、`GET /api/run/<id>`、
`GET /api/compare?baseline=<id>&candidate=<id>`、`POST /api/run`、`POST /api/cancel`、
`POST /api/prompt`、`POST /api/review`。本机浏览器自动附加会话令牌。

测试集视图使用`dataset`和`view=current|original`查询参数，单样本比较额外传入`case`。
`GET /api/case-runs/<id>`读取相同输入的历史实验；`POST /api/exclusion`提交`id`、`excluded`、
必填`reason`及当前`revision`，执行同源与版本检查后写入资格事件。
