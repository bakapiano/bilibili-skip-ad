# 全文摘要 + 完整字幕：非思考两阶段实测

2026-10-02，对 MC `BV1Lmd2BAEad` 和航母 `BV1eVaz6UENn` 各执行 5 轮。
每轮独立生成摘要，再发送摘要、标题和完整字幕识别广告，共 10 个结果、20 次真实 API 请求。

## 方法

第一阶段使用 `prompt/variants/summary-first.js` 的摘要指令，要求用自然语言概括主题、对象、叙事顺序、转折与结论。
提示中把区间编号和广告分类留给后续任务。模型输出约 200 tokens 的摘要，部分摘要自行提到“插入广告”。

第二阶段使用此前内部分类实验完全相同的 system prompt，将第一阶段摘要作为辅助数据附在完整字幕后。
摘要以 JSON 字符串编码，标明以字幕核对实际语义与边界。最终直接解析五列广告，逐轮保留两个阶段的实际请求和回复。

两阶段均为 `deepseek-flash`、`thinking: disabled`、temperature 0。
摘要输出上限 1024 tokens，广告输出上限 2048 tokens；每轮重新生成摘要，视频任务并发 2。
与历史对照按相同字幕比较，新增摘要使完整模型输入发生变化，因此作为流程实验单独记录。

这些数字反映参考区间一致性，单独保留上述正文检查结果。

## 摘要提供了什么

MC 摘要能概括流程控制、两种流派、任务书和制作动机，也会写出中途介绍得物耳机后回到评测。
航母摘要能概括历史案例、结构防护、游戏插入和结尾观点，但倾向把两次游戏介绍压缩成一个中段插入。
第二阶段即使有完整字幕，仍然把同品牌两端连接成一个广告。

本组观察支持：整体主题已经相当清楚，局部正文恢复和起止编号绑定仍是瓶颈。
这是对本版摘要和两个样本的解释；更细的带区间分段摘要属于另一种待测方案。
