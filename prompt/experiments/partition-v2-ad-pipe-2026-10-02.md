2026-10-02。用户希望把通过两例重复测试的仅广告 JSON v2 改回原五列格式。
保留广告判定规则及 v2 分段思路，做了两种格式说明，每种两视频各 5 次，合计 20 次新 API 调用。
全部为 DeepSeek Flash 非思考、temperature 0。

## 格式转换的范围

基线是 `PARTITION_V2_AD_ONLY_PROMPT`，本次候选从它逐项转换：

- JSON `start/end/subject/reason/confidence` 映射为 `起始编号|结束编号|品牌|简短说明|评分`。
- 每条输出均为广告，因此隐含 `type: ad`；`topic` 由显式输出移入内部主题判断。
- 零广告时回复单行 `NONE`。
- 关闭请求的 JSON 格式开关，输出上限仍保持 8192 tokens，便于和 JSON 实验对照。
- 标题、完整字幕、评分阈值和 50% 保护保持一致。程序直接使用生产五列解析器。

这些改变包含输出表示、显式主题输出和请求格式模式。因此回退的因果无法仅归于 JSON 或竖线字符。
对照的 JSON 10 个结果来自上一轮已完成批次，本轮新请求用于两种五列候选。
