# 仅广告 JSON v2：固定1000条社区样本评测

日期：2026-10-02。评测任务已完成，生产提示词、扩展和油猴发布产物保持原样。

## 结论

JSON v2 提高了广告召回与区间重叠度，同时扩大了社区参考范围以外的自动跳过。
在双方有效的993份输入上，IoU增加3.967个百分点，广告遗漏率降低5.075个百分点，
正文误跳率增加0.1308个百分点。两处已知穿插正文（MC、航母）本轮均完整保留。

字幕初筛还发现两个值得优先复核的问题：把剧情中的仿营销台词识别为商业推广，
以及把游戏评测内的获取方式／游戏内消费说明判成独立植入。149份输入触发既有必审阈值。
人工复核这些问题后再作发布决策；本轮原始参考、移除资格和模型结果完整保留。

## 数据与调用范围

- 固定1000份输入、999个不同BV。原567份加新增433份；同一BV的两份不同输入沿用原集。
- 每份有完整字幕与社区`sponsor/skip`参考，按冻结名单重新核验身份、字幕指纹和参考指纹。
- 全局原有3条移除记录继续生效，91份备用输入留在采集库。
- 原版复用身份和参考一致的567份历史结果，新增433次；候选1000份全部新调用。
- 合计1433次新API调用，每份每方案一次、8路并发、6个分批。所有调用均保存usage。
- `deepseek-flash`，非思考，temperature 0；原版五列／2048输出预算，候选JSON／8192。
- 候选SHA-256：`14bc43424ab7c164d70a9cf88d1ff179fd53b96e3ad72369127cc34a5b9163d7`。
- 原版SHA-256：`66c1984919801b1022b467593dd636815732eb826df95bd204d19ea47a8e8438`。

双方各996份有效输出、4份协议失败，失败交集1份，双方有效配对993份。
主对照仅比较相同输入／参考／返回模型；补充口径纳入全部1000份，失败当次按空跳过计算。
这是提示词、输出协议和预算的方案对照，结果用于评估整套改动。
