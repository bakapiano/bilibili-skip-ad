# 完整分类 v2：只省略正文 block 的对照

2026-10-02。用户要求从之前效果较好的完整分类 v2 出发，保留广告段并省略正文段输出。
本轮对原始 v2 和仅广告版分别发送全新请求，每版两个视频各 5 次，共 20 次真实调用。

## 改动范围

沿用 `PARTITION_V2_PROMPT`，修改以下输出选择，全部判定规则、四条边界复核规则和烤面包示例逐字保留：

1. 开头输出要求改为先完成全片分类，最终 `blocks` 只返回 `type: "ad"` 的区间。
2. JSON 结构示意里省略 `body` 示例对象，保留 `topic` 和广告对象的 `start/end/type/subject/confidence/reason`。
3. 末尾明确每个广告段按顺序独立保留；全片均为正文时返回空 `blocks`。

完整 prompt 位于 `prompt/variants/body-islands.js` 的 `PARTITION_V2_AD_ONLY_PROMPT`。
单元测试逐项逆变换后与原 v2 完全相等，并校验整个边界规则与叙事示例保持一致。

解析器采用 `partition-ad-only`：接受有序广告区间之间的编号空缺，校验字段、边界、评分及互不重叠。
正文对象被输出时作为协议错误；正常零广告输出为 `{"topic":"主题","blocks":[]}`。
程序直接提取模型给出的广告段并映射字幕时间，各段原样保留。每个结果仅一次模型调用。

## 相同条件的新请求

- 模型：`deepseek-flash`；`thinking: disabled`；temperature 0；`response_format: json_object`。
- 原版和候选的输出上限均为 8192 tokens，单批视频任务并发 2。
- 标题、完整字幕、编号、参考快照与有效名单一致，实际请求逐字段核验：只有 system prompt 文本发生变化。
- 先跑原始 v2 的 10 次，再跑候选 10 次；同一次实验中两组均为新调用。
- 原 JSON 字段保留，用于隔离“省略正文输出”这一改动；本轮维持 JSON 协议。
- 当前样本已被前序实验反复查看，因此结论用于这两个已知问题的验证。泛化与发布判断仍需其他样本。
