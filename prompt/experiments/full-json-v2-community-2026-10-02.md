# 仅广告 JSON v2：567 个有效社区样本全量评测

日期：2026-10-02。本轮按用户要求先验证全量识别表现，扩展／油猴新版制作与发布继续暂停。

## 结论

JSON v2 的整体 IoU 提升、广告遗漏减少，同时增加了社区参考范围之外的自动跳过。
两个已知穿插正文问题（MC、航母）在本轮正确拆开；其他样本仍有新增标记、边界扩张与广告引入语遗漏。
当前适合进一步复核回退样本，发布决策应把正文安全性和召回收益一起考虑。

零广告误报率还需要独立的人工零广告集。每份本轮仅测一次，重复稳定性仍需另评估。
