# 内部分段后仅输出广告：20 次实测

日期：2026-10-02。用户希望把全片正文／广告分类写进 Prompt 内部步骤，最终仍只返回五列广告。

## 实现与控制

在原版 `第三步：` 之前插入上一条回复拟定的完整五条分类指令，其余原始文字保持原样。
提示词为 `prompt/variants/body-islands.js` 的 `internal-classify-pipe`，插入文本常量为
`INTERNAL_CLASSIFICATION_STEPS`。单元测试验证去掉这一新增文本即可还原整个生产提示词。

- 生产提示词 SHA-256：`66c1984919801b1022b467593dd636815732eb826df95bd204d19ea47a8e8438`。
- 实验提示词 SHA-256：`cd8c784e21bf2e6baa1125e10e3d8bc422fe64d5353d3301dc817b76661dc0dd`。
- 模型 `deepseek-flash`，`thinking: disabled`、temperature 0、输出上限 2048 tokens。
- 同样的完整标题和精简字幕输入，每次单独调用；两批各 5 轮，每轮两个视频，合计 20 次。
- 程序直接使用五列解析与字幕时间映射；本实验处理链只有一次模型判定。
- 原始模型区间与评分完整保留，实际跳过仍按评分 ≥0.90 和原始 50% 保护计算。
- 两批使用同一个冻结提示词，执行前后字幕身份与有效名单版本保持一致。

| 视频               | 格式有效 | 专项正文完整保留 | 每轮广告 ID 区间   | 每轮正文误圈 |
| ------------------ | -------- | ---------------- | ------------------ | ------------ |
| BV1Lmd2BAEad，MC   | 10/10    | 0/10             | 1–72，评分 0.98    | 124.310 秒   |
| BV1eVaz6UENn，航母 | 10/10    | 0/10             | 129–178，评分 0.95 | 30.148 秒    |

两例十轮的区间与此前原版基线一致。原始正文覆盖与实际跳过正文覆盖一致，模型评分均高于阈值。

专项正文范围沿用上一轮：MC 1.660–125.970 秒是本轮系列中按字幕阅读设定的实验检查区；
航母 370.904–401.052 秒是用户确认正文。MC 检查区继续与正式人工标注分开保存。

因此，本版“内部分类后输出广告”指令未在这两个样本改善跨正文合并。
模型是否真正完成内部分类，最终回复无法核验。
