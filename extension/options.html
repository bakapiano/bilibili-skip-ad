模型与隐私

模型固定为 deepseek-flash，采用非思考模式和 JSON 输出。

Key 存放在当前浏览器的扩展专属存储，访问范围限于扩展后台和设置页。请使用专用额度 Key。本机扩展存储适合保存个人设置，应与电脑账号一起保护。

播放行为

建议先试听边界。标记累计超过视频一半时保留手动操作；撤销后本轮会保留对应片段。评分是模型自评，适合配合人工检查。

原生进度条的金色区间表示广告。自动跳过开启时，主动定位进符合阈值的广告区间会跳至末尾；暂停时的定位也会响应，播放与暂停行为沿用 B站原生控件。

线上共享缓存 默认读取 · 自动上传

内置服务为 biliskipad.bakapiano.com。查询发送当前视频标识、字幕指纹与模型版本；新分析结果保存到本地后默认自动上传，供其他用户复用。

本地缓存优先；工具栏弹窗中的「读取线上缓存」可主动刷新。自动与手动上传均包含视频信息、广告区间和有限证据句。关闭自动上传后，可使用弹窗按钮手动提交。上传失败时保留本地标记，可手动重试。服务记录提交 IP 及次数，逻辑保留最近 7 个 UTC 日期，每个 IP 每秒最多提交一次。

本地数据库

缓存以视频 BV、分 P、CID、字幕指纹、模型和提示词版本区分。重新进入视频时先核对字幕，命中后复用结果。
