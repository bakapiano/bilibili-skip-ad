B站植入广告跳过插件

从视频字幕中识别赞助口播等广告片段，在进度条上标记，并按设置自动跳过。

识别使用你自己的 DeepSeek API Key。已有结果会优先从本地或共享缓存读取。

安装 Chrome 扩展

Chrome 120+ · 当前版本 v{{VERSION}}

下载 Chrome 扩展（ZIP） SHA-256
  1. 下载 ZIP，解压到固定文件夹，例如 BiliSkip。
  2. 在 Chrome 地址栏输入 chrome://extensions，开启右上角「开发者模式」。
  3. 点击「加载已解压的扩展程序」，选择包含 manifest.json 的解压文件夹。
  4. 打开 B站视频，点击工具栏的 BiliSkip 图标。需要新识别时，在设置中填写个人 DeepSeek API Key 并确认字幕发送授权。

本页提供 ZIP 离线加载包，导入时选择解压后的文件夹。更新时覆盖原目录中的扩展文件，在扩展管理页重新加载，再刷新视频页。

固定下载地址：https://biliskipad.bakapiano.com/downloads/biliskip.zip

安装油猴脚本

Chrome 120+ · Tampermonkey 5.4+ · 通过 Greasy Fork 发布

前往 Greasy Fork 安装 获取 Tampermonkey
  1. 在浏览器中安装 Tampermonkey，并按它的提示完成脚本运行配置。
  2. 打开上面的 Greasy Fork 页面，点击「安装此脚本」，再在油猴确认页点击「安装」。
  3. 刷新 B站视频页，点击工具栏的油猴图标，选择「BiliSkip · 打开面板」。
  4. 需要新识别时，通过「BiliSkip · 配置 DeepSeek Key」填入个人 Key，再在「BiliSkip · 设置」确认字幕发送授权并保存。

后续通过油猴检查脚本更新，安装新版后刷新 B站视频页。

两个版本各自保存 Key、设置和本地缓存，共用线上缓存。请选择其中一个版本运行；已有共享结果可直接读取。

功能

广告标记与跳过
在原生进度条显示广告区间。自动跳过开启后，播放或主动定位进广告时会跳到末尾，重复定位同样生效。
试听与撤销
可以试听广告边界、手动跳过，或撤销跳转回到原位置。
字幕选择
按中文、英文、其他语言的顺序尝试可用字幕，同组优先人工字幕。
本地与共享缓存
按视频、字幕指纹和模型版本复用结果。识别为 0 段广告的结果也会缓存。
视频切换
跟随侧边推荐和分 P 切换更新标记。关闭操作面板后，已开始的分析和自动跳过会继续执行。

使用前请了解

模型费用

新分析由 DeepSeek 按你的 API 账户用量计费。命中缓存时直接复用结果；点击「重新分析（再次计费）」会发起新的模型请求。

共享上传

共享查询和自动上传默认开启。新分析结果会先保存本地，再默认上传视频信息、广告标记和有限证据句。设置中可以单独关闭自动上传，也可以关闭全部共享上传。

识别准确度

当前依赖可获取的带时间戳字幕，结果会受字幕内容和模型判断影响。建议先试听确认边界，遇到误判可以撤销跳过。
