安装与使用

  1. 下载 ZIP，解压到固定目录。
  2. 打开 chrome://extensions，开启「开发者模式」，点击「加载已解压的扩展程序」，选择包含 manifest.json 的文件夹。
  3. 在扩展设置中填写 DeepSeek API Key，并确认字幕发送授权。
  4. 打开 B站视频，点击工具栏的 BiliSkip 图标。可以先读取缓存，或点击「分析当前视频」，试听边界后开启自动跳过。

更新时，将新版本解压到原扩展目录，在扩展管理页重新加载，再刷新视频页。

功能

广告标记与跳过
在原生进度条显示广告区间。自动跳过开启后，播放或主动定位进广告时会跳到末尾，重复定位同样生效。
试听与撤销
可以试听广告边界、手动跳过，或撤销跳转回到原位置。
字幕选择
按中文、英文、其他语言的顺序尝试可用字幕，同组优先人工字幕。
本地与共享缓存
按视频、字幕指纹和模型版本复用结果。识别为 0 段广告的结果也会缓存。
视频切换
跟随侧边推荐和分 P 切换更新标记。关闭插件弹窗后，已开始的分析和自动跳过会继续执行。

使用前请了解

模型费用

新分析由 DeepSeek 按你的 API 账户用量计费。命中缓存时直接复用结果；点击「重新分析（再次计费）」会发起新的模型请求。

共享上传

共享查询和自动上传默认开启。新分析结果会先保存本地，再默认上传视频信息、广告标记和有限证据句。设置中可以单独关闭自动上传，也可以关闭全部共享上传。

识别准确度

当前依赖可获取的带时间戳字幕，结果会受字幕内容和模型判断影响。建议先试听确认边界，遇到误判可以撤销跳过。
