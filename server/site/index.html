安装 BiliSkip

选择安装方式

安装 Chrome 扩展

Chrome 120+ · 本站 ZIP v{{VERSION}} · 商店版本以商店页面为准

前往 Chrome 应用商店安装
  1. 打开上面的 Chrome 应用商店页面，点击「添加至 Chrome」并确认安装。
  2. 在工具栏的扩展菜单中固定 BiliSkip，方便随时打开操作面板。
  3. 打开 B站视频，点击工具栏的 BiliSkip 图标。需要新识别时，在设置中填写个人 DeepSeek API Key 并确认字幕发送授权。

商店安装版通过 Chrome 更新。已有油猴版或开发版的用户，请选择一个版本控制播放器；切换安装方式时重新配置个人设置。

ZIP / 源码安装方式
下载 ZIP（v{{VERSION}}） SHA-256
  1. 下载 ZIP，解压到固定文件夹，例如 BiliSkip。
  2. 在 Chrome 地址栏输入 chrome://extensions，开启「开发者模式」。
  3. 点击「加载已解压的扩展程序」，选择包含 manifest.json 的文件夹。

ZIP 导入时选择解压后的文件夹。更新时覆盖原目录中的扩展文件，在扩展管理页重新加载，再刷新视频页。

安装油猴脚本

Chrome 120+ · Tampermonkey 5.4+ · 通过 Greasy Fork 发布

前往 Greasy Fork 安装 获取 Tampermonkey
  1. 在浏览器中安装 Tampermonkey，并按它的提示完成脚本运行配置。
  2. 打开上面的 Greasy Fork 页面，点击「安装此脚本」，再在油猴确认页点击「安装」。
  3. 刷新 B站视频页，点击工具栏的油猴图标，选择「BiliSkip · 打开面板」。
  4. 需要新识别时，通过「BiliSkip · 配置 DeepSeek Key」填入个人 Key，再在「BiliSkip · 设置」确认字幕发送授权并保存。

后续通过油猴检查脚本更新，安装新版后刷新 B站视频页。

两个版本各自保存 Key、设置和本地缓存，共用线上缓存。请选择其中一个版本运行；已有共享结果可直接读取。

0.2 新增 · Chrome / 油猴

吃白饭，也干活的宠物搭子

用 DeepSeek 识别并自动跳过恰饭片段时，让宠物用气泡告诉你进展。无聊的时候，也可以戳一戳。

  • 状态气泡：识别、完成与自动跳过都有对应台词，完成后可查看本次参考费用。
  • 点击互动：回弹、小黄鸭音效和待机台词，点击气泡里的 Logo 可打开面板。
  • 随手安放：支持拖动、左右镜像与贴底，气泡根据可用空间展开。
  • 自己定制：上传并裁剪图片，修改台词，上传点击音频；默认音量 10%。

设置 → 宠物 → 开启显示
首次安装默认关闭，开启后即可使用。

适用于 0.2 及以上版本。本站 ZIP 和商店版本请查看安装区；也可获取 0.2 源码版。

功能

广告标记与跳过
在原生进度条显示广告区间。自动跳过开启后，播放或主动定位进广告时会跳到末尾，重复定位同样生效。
试听与撤销
可以试听广告边界、手动跳过，或撤销跳转回到原位置。
宠物搭子（0.2）
状态气泡、点击回弹与音效，支持图片、台词和点击音频自定义。查看实机截图与开启方式。
字幕选择
按中文、英文、其他语言的顺序尝试可用字幕，同组优先人工字幕。
本地与共享缓存
按视频、字幕指纹和模型版本复用结果。识别为 0 段广告的结果也会缓存。
视频切换
跟随侧边推荐和分 P 切换更新标记。关闭操作面板后，已开始的分析和自动跳过会继续执行。

使用前请了解

模型费用

新分析由 DeepSeek 按你的 API 账户用量计费。命中缓存时直接复用结果；点击「重新分析（再次计费）」会发起新的模型请求。

共享上传

共享查询和自动上传默认开启。新分析结果会先保存本地，再默认上传视频信息和广告标记，旧版还可能附带有限证据句。设置中可以单独关闭自动上传，也可以关闭全部共享上传。

识别准确度

当前依赖可获取的带时间戳字幕，结果会受字幕内容和模型判断影响。建议先试听确认边界，遇到误判可以撤销跳过。
