隐私与数据说明

适用扩展版本：{{VERSION}} · 更新日期：2026 年 9 月 29 日

BiliSkip 是由 bakapiano 维护的开源 Chrome 扩展，用于依据 B站字幕识别商业植入、标记时间轴和辅助跳过。本页说明当前实现中的数据流向、保存方式与用户控制。

1. 哪些数据保存在你的浏览器？

  • Key 与设置：个人 DeepSeek API Key、可选共享服务令牌、共享服务地址、授权与行为开关，保存在 chrome.storage.local。扩展将存储访问范围限制为可信扩展上下文。
  • 视频与识别结果：视频 BV、分 P、CID、标题、时长、字幕文本与时间戳、广告区间、证据、字幕指纹和模型版本，保存在浏览器 IndexedDB。
  • 任务与运行记录：分析状态、参考用量与费用、耗时、缓存命中及错误信息用于展示与排查；近期事件记录上限为 200 条。

本地数据可保留至你清理缓存、清除凭据或卸载扩展。本机扩展存储的保护依赖浏览器、电脑账号与设备安全措施。

2. 数据会发送给哪些服务？

  • B站：扩展请求当前视频信息和可用字幕，字幕 CDN 提供字幕文件。B站 API 请求按浏览器规则沿用已有登录态。
  • DeepSeek：配置个人 Key 并确认授权后，新分析会将当前视频信息、标题、字幕、字幕指纹和识别指令发送到官方 API。Key 仅用于 DeepSeek 请求认证。第三方处理规则与计费以你的账户安排和提供方政策为准。
  • 共享缓存：默认服务为 biliskipad.bakapiano.com。查询发送视频标识、字幕指纹、模型和提示词版本。新分析结果保存到本地后，默认自动上传视频信息、广告标记和有限证据句；每段最多 10 条证据，每条最多 500 字符。0 段广告也属于可共享的有效结果。

共享请求采用字段白名单。DeepSeek Key 与 B站会话分别留在各自的认证链路；自定义共享令牌按服务域名绑定。网络连接本身会向接收方提供 IP 等必要的网络信息。

3. 共享服务器保存什么？

服务器使用 SQLite 保存共享标记。按来源 IP 记录提交次数、限流次数和入库次数；IPv6 以 /64 网段统计。计数按最近 7 个 UTC 日期滚动清理，每个来源两次放行至少间隔 1000ms。

共享标记持续用于后续缓存查询，维护者可以撤销记录。业务数据库备份、运行错误和基础设施日志按运维需要管理，IP 计数的滚动清理范围指业务计数表。本站介绍页仅加载本域静态资源。

4. 你可以如何控制？

  • 在设置中分别调整自动分析、自动跳过、共享查询和自动上传。
  • 关闭「分析完成后自动上传到共享缓存」，保留手动上传；关闭「允许上传」总开关，同时停止后续自动与手动提交。
  • 在设置中清除个人 Key、删除本地标记、清空缓存与候选队列，或导出标记自行管理。
  • 为共享功能配置自己的 HTTPS 服务地址，数据会依照对应开关发送到该服务。

开关调整对后续操作生效，已发出的请求和已共享的记录可由相应服务进一步处理。反馈共享记录问题时，可提供 BV 号与相关区间，方便维护者定位。

5. 准确性与反馈

广告判断来自字幕与模型，可能出现遗漏或边界偏差。共享服务的频率和结构校验用于控制提交行为，语义准确性仍依赖识别结果。建议通过试听、撤销和人工核对使用标记。

项目和联系渠道：GitHub 仓库与 Issues。公开反馈请仅提供排查所需的脱敏信息，凭据由你在对应提供方管理。
